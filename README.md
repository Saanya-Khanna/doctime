
DocTime is a healthcare appointment scheduling platform built with Python and Streamlit. It provides separate patient and doctor portals, allowing users to search for healthcare providers, view appointment availability, and manage appointments through a modern dashboard interface.

Status: Frontend prototype (actively being developed)


Features

Patient Portal

* Secure demo login
* Dashboard with appointment overview
* Search doctors by specialty and ZIP code
* View doctor availability
* Book appointments
* Manage upcoming appointments
* Edit profile information
* User settings

Doctor Portal

* Separate doctor login
* Dashboard overview
* View scheduled appointments
* Manage availability
* Profile management


Tech Stack

* Python
* Streamlit
* HTML/CSS
* Session State
* Modular application architecture
